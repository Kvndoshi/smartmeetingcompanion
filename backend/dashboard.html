Chrome Extension

  1. Open chrome://extensions in Chrome
  2. Enable Developer Mode (top right toggle)
  3. Click Load unpacked
  4. Select the interpreter/extension/dist folder
  5. Open any tab with audio (YouTube, Google Meet, etc.)
  6. Click the Interpreter extension icon and start translating
